Первый запуск. Создай токен: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → scope gist. Открыть форму

Токен хранится только в localStorage этого браузера. На втором устройстве вставь тот же токен — найдёт тот же Gist сам.
Быстрый вход: открой …/#token=ТВОЙ_ТОКЕН — токен сохранится, а адрес очистится.
