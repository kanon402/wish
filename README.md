# вишлист

уютное приложение-вишлист на двоих: две вкладки — «никита» (тёмно-зелёная) и «ника» (нежно-розовая).

## что умеет

- две вкладки с разными темами, переключение в одно касание
- добавление, редактирование и удаление вишей
- попап с загрузкой фото, названием и необязательной ссылкой на покупку
- все картинки автоматически обрезаются в один квадратный формат (640×640), поэтому карточки выглядят одинаково
- полностью адаптивная вёрстка для телефонов
- всё на русском, без заглавных букв
- маленькие зверята (лягушка, улитка, котёнок, фея и панда) изредка проползают по кнопкам — примерно раз в минуту на несколько секунд

## как это работает

это статическая страница без сборки и без сервера. виши хранятся в `localStorage` браузера,
у каждой вкладки — свой список. фото сохраняются вместе с вишем в виде data url.

## запуск локально

просто открой `index.html` в браузере, либо:

```
python3 -m http.server 8000
```

и зайди на `http://localhost:8000`.

## публикация

**github pages:** в настройках репозитория `settings → pages → source` выбери `github actions`.
воркфлоу `.github/workflows/pages.yml` соберёт и опубликует сайт при пуше.

**netlify:** подключи репозиторий, каталог публикации — корень (`.`), команда сборки не нужна
(это уже прописано в `netlify.toml`). можно и просто перетащить папку в netlify drop.

## файлы

- `index.html` — разметка
- `styles.css` — темы и адаптив
- `app.js` — логика: хранение, попапы, обработка фото, зверята
